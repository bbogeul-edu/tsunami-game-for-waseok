# 지진해일에서 살아남기

와석초등학교 2학년용 지진·지진해일 안전교육 인터랙티브 게임 (태블릿용).

- `index.html` : 게임 전체 (화면, 대본, 엔진, 효과음, 배경 음악)
- `img/` : 장면 배경 그림 13장
- `img/face/` : 인물 프로필 얼굴과 표정

빌드 과정이 없는 정적 사이트라서 Vercel에서 Framework Preset을 "Other"로 두고 그대로 배포하면 돼요.

## 버전 기록

### v1.1.0
- 선택지 다듬기: 정답·오답의 길이와 말투를 비슷하게 맞추고, 따옴표를 없앴어요.
- 오답을 고르면 결과 장면 → "왜 위험했을까요?" 설명 → 친구들의 대화(남 탓, 앞으로는 이렇게 하자)가 이어져요.
- 정답을 고르면 친구들이 좋은 선택이었다고 말해 줘요.
- 왼쪽 위 진행 막대: 지금 몇 장인지, 전체 8장 중 얼마나 왔는지 보여줘요.
- 뒤로(앞 대사 다시 보기), 건너뛰기(다음 선택지까지), 다시(이 장 처음부터 / 1장부터) 버튼을 넣었어요.
  - 이미 고른 선택보다 앞으로는 돌아갈 수 없어요. (틀린 답을 지워 하트를 되살리지 못하게)

### v1.0.0
- 첫 배포: 0~8장, 하트·세이브·힌트, 행정안전부 카드뉴스, AI 배경 13장, 인물 표정, 효과음·배경 음악.
